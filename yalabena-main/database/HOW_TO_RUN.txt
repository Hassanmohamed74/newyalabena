-------------
Put all three files into:

C:\Users\WinDows\Desktop\newspeakup-main\database\

newspeakup-main
└── database
    ├── seed-test-data.ps1
    ├── seed-test-data.sql
    ├── TEST_USERS_AND_PASSWORDS.txt
    └── HOW_TO_RUN.txt

-----------------------------------------

STEP 2 - Allow the script for this PowerShell session
------------------------------------------------------
Run:

------------------------------
Run:

cd "C:\Users\WinDows\Desktop\newspeakup-main"
.\database\seed-test-data.ps1

OR, from inside the database folder:

cd "C:\Users\WinDows\Desktop\newspeakup-main\database"
